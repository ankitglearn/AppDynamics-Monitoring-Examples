Steps to setup Cluster agent on EKS cluster:

1.	Delete all the previously installed CustomResourceDefinition (CRDs) related to Splunk AppDynamics Agent by using these commands:

$ kubectl get crds

Lists all CRDs currently installed in your cluster.
Purpose: Check if any old AppDynamics CRDs exist from a previous installation.

$ kubectl delete crds <crd-names>

Deletes outdated or conflicting CRDs.
Purpose: Prevent version conflicts between old CRDs and the new Helm chart installation.
If old CRDs remain, the new Operator might fail or behave incorrectly.


2.	Add the chart repository to Helm:

helm repo add appdynamics-cloud-helmcharts https://appdynamics.jfrog.io/artifactory/appdynamics-cloud-helmcharts/

By adding this repo, you tell Helm where to find the official AppDynamics Cluster Agent chart.


3.	Create a namespace for appdynamics in your cluster:

kubectl create namespace appdynamics

To check what all namce space is present 

kubectl get namespaces

4. create values.yaml / values-ca1.yaml /opt/appdynamics-helm/values.yaml


# To install Cluster Agent 
installClusterAgent: true


# controller info
controllerInfo:
  url: https://takeda.saas.appdynamics.com:443
  account:  takeda
  accessKey: dcf911d3-61b3-4e71-bd1d-39a945c56ad8  

# Cluster agent config

clusterAgent:
  createSecret: true
  nsToMonitorRegex: ^(dash-.*|plotly-.*)$
  appName: APMS-10758-BSN0020183-PlotlyDash-Prod
  

# Subcharts boolean install switches
install:
  metrics-server: false
  
or 

•	kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

Metrics Server is a lightweight aggregator that collects resource usage metrics (CPU, memory) from all nodes and pods.
The AppDynamics Cluster Agent relies on these metrics to display accurate resource utilization in the Controller dashboards.

6. To see the informastion regarding available configration use below commands

helm show values appdynamics-cloud-helmcharts/cluster-agent


7.	Deploy the Cluster Agent to the appdynamics namespace:

helm install cluster-agent appdynamics-cloud-helmcharts/cluster-agent \
  --namespace appdynamics \
  -f /opt/appdynamics-helm/values.yaml \
  --version 1.34.1544


helm upgrade --install cluster-agent appdynamics-cloud-helmcharts/cluster-agent \
  --namespace appdynamics \
  -f /opt/appdynamics-helm/values.yaml \
  --version 1.34.1544 \
  --reset-values



8. Validate Installastion 

helm status cluster-agent -n appdynamics

kubectl get pods -n appdynamics

9. Check logs

kubectl logs <pod-name> -n appdynamics


clusterName: APMS-10758-BSN0020183-PlotlyDash-Test
